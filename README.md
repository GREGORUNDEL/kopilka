# Копилка

Накопления на переезд в Японию: недели, прогноз по SNG и KAI для двух бюджетов, курс иены.

Приложение: https://gregorundel.github.io/kopilka/

- Работает офлайн (service worker), данные хранятся на устройстве.
- При наличии сети синхронизируется с приватным репозиторием `kopilka-data` (файл `kopilka.json`) через fine-grained токен, введённый в самом приложении.
- Курс EUR/JPY берётся из ЕЦБ через api.frankfurter.dev.

Личных данных в этом репозитории нет.
