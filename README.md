# Копилка

Учёт расходов и доходов с накоплениями на переезд в Японию.

Приложение: https://gregorundel.github.io/kopilka/ · прежняя версия (только Копилка): https://gregorundel.github.io/kopilka/old/

- Обзор: расходы/доходы по категориям за день, неделю, месяц, год или период; карточка недели с нормой Копилки.
- Операции: список по дням, поиск, фильтры, переводы и корректировки.
- Копилка: прогноз по SNG и KAI для двух бюджетов. Недели с даты «Недели из операций» считаются из учёта, раньше — ручные.
- Графики: общий (доходы, расходы, прибыль/убыток) и по категориям.
- Счета: несколько валют, переводы с фактическими суммами списания и зачисления.
- Работает офлайн (service worker), данные на устройстве и в приватном репозитории `kopilka-data` (`finance.json`).
- Курсы: EUR/JPY — ЕЦБ через api.frankfurter.dev, прочие валюты — open.er-api.com.
- Иконки: Tabler Icons (MIT).

Личных данных в этом репозитории нет.
